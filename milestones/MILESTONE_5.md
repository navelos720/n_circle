# MILESTONE 5 — Internal Release

## Objectives
- Build the installation script and company-default configuration seeding (`../docs/INSTALLATION.md`).
- Implement configuration migration for any schema changes made since Milestone 1 (`../docs/UPDATE_SYSTEM.md`).
- Complete a full testing pass, including the clean-machine install test (`../docs/TESTING.md` section 6).
- Finalize all documentation to reflect actual, implemented behavior (no stale spec sections).
- Package the final release (`../docs/RELEASE.md`).

## Deliverables
- A signed-off, installable `.zxp` package plus install/uninstall scripts.
- A completed final QA checklist on a genuinely clean test machine.
- Final `RELEASE_NOTES.md`, `INSTALLATION.md`, and `CHECKSUMS.txt` under `releases/final/`.

## Demo Checklist
See `../docs/TESTING.md` section 6.

## Success Criteria
The production team can install and use the tool without developer assistance; existing configurations survive supported updates; critical workflows are stable; a final installable release package exists and has passed at least one clean-machine install test.
