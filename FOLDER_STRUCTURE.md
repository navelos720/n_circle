## 2. Plugin Source Code Repository (separate from docs, created during implementation)
```text
/ae-radial-plugin
├── CSXS/
│   └── manifest.xml        # CEP extension manifest — see TOOLS.md, do not create a UXP manifest.json
├── index.html               # Panel entry point
├── /src
│   ├── /components          # UI components: SuitePanel, RadialOverlay, SettingsModal, etc.
│   ├── /state                # State store for panel + radial overlay
│   ├── /utils                # Helpers: path resolution, command execution wrapper, angle math
│   └── /scripts               # ExtendScript (.jsx) bridge code, called via CSInterface.evalScript()
├── /assets                  # Icons, default thumbnails
├── /build                   # Compiled output (never edit by hand)
├── Install_Plugin.bat        # or .ps1 — see docs/INSTALLATION.md and RELEASE.md
└── Uninstall_Plugin.bat
```
